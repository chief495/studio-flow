Фронтенд написан на TypeScript. Исходники находятся в src/app.ts.
Файл wwwroot/js/app.js генерируется компилятором — не редактируйте его вручную.

Из каталога StudioFlow:

    npm ci
    npm run build

Проверка типов: npm run typecheck
Пересборка при изменениях: npm run dev

ASP.NET Core раздаёт скомпилированный JavaScript. В Docker сборка выполняется автоматически.
